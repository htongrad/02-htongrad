# Подключение Google к панели 02 «Хтонград»

Можно использовать проект Google Cloud, OAuth Client ID и ключ Google Picker панели «Личное». Для обеих панелей источник один — `https://htongrad.github.io`.

1. Откройте [Data Access](https://console.cloud.google.com/auth/scopes) в том же проекте Google Cloud. К разрешениям `openid`, `drive.file` и `calendar.events.owned` добавьте `https://www.googleapis.com/auth/calendar.calendarlist.readonly`. Панель использует его для поиска отдельного календаря «02 ХТОНГРАД».
2. В [панели «Хтонград»](https://htongrad.github.io/02-htongrad/) откройте «⋯ → Синхронизация Google». Вставьте OAuth Client ID, числовой Project number и ключ Google Picker. Нажмите «Сохранить настройки».
3. Нажмите «Синхронизировать» в «Обзоре». Если Google запросит вход, подтвердите его. При первом подключении выберите папку «02 ХТОНГРАД». В том же аккаунте должен быть один отдельный календарь «02 ХТОНГРАД», принадлежащий аккаунту.
4. В папке появится JSON с датой копии, а события панели обновятся в календаре «02 ХТОНГРАД». В «Обзоре» появится время последней успешной синхронизации.

При изменении записей панель создаёт новый файл. Предыдущие копии остаются на Диске. Повторная отправка тех же записей использует актуальную копию. События, созданные непосредственно в Google Календаре, остаются там.

Открытая панель автоматически отправляет сохранённые изменения, пока доступ Google действует. Если сеть пропала, отправка возобновится после её возвращения при действующем доступе. Кнопка «Синхронизировать» возобновляет отправку после повторного входа.

На новом телефоне или после очистки данных браузера сохраните настройки Google. Откройте «⋯ → Синхронизация Google → Восстановить последнюю копию». При необходимости подтвердите вход и выберите папку «02 ХТОНГРАД». После предварительного просмотра нажмите «Подтвердить восстановление». Панель добавит отсутствующие записи и сохранит локальные версии совпадающих.
