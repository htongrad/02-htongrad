# 02 «Хтонград»

Мобильная писательская мастерская. Откройте [панель](https://htongrad.github.io/02-htongrad/) в Chrome.

- «Обзор» показывает последний текст, ближайшие сроки и свежие заметки.
- «Тексты» объединяют прозу, сценарии и публицистику. Форма определяет стартовые блоки и допустимую структуру. В редакторе можно свернуть, дублировать и переместить блок. Предпросмотр автоматически оформляет заполненные поля. В публицистике доступны отдельные шаблоны для репортажа и объясняющей статьи.
- «Заметки» можно хранить отдельно или прикреплять к проекту.
- «Календарь» показывает день, неделю или месяц. Событие можно связать с текстом.
- Объём считается по заголовку и тексту предпросмотра. В авторском листе 40 000 знаков с пробелами. Для сценариев можно задать целевой хронометраж в свойствах.
- В «Плане сценария» хранятся логлайн и поэпизодный план. «Анализ сцен» показывает сцены по порядку и раскрывает их действия и реплики.

Рабочие данные сохраняются в открытом браузере. Меню «⋯ → Копии данных» позволяет экспортировать и восстановить JSON. Правила подключения Google описаны в [инструкции](google-sync-setup.md).

**Сборка 1.3.0.** После первого открытия с интернетом панель запускается и без сети. Для обновления откройте её с интернетом, затем закройте все окна и вкладки панели и откройте снова. Номер сборки виден в меню «⋯».

Если сохранение абзаца прервалось, его можно скопировать из черновика в открытой вкладке. Если локальные записи не читаются, панель приостанавливает запись и предлагает скачать исходные данные перед восстановлением. Введённые значения в форме Google сохраняются при смене статуса сети.

Кнопка «Синхронизировать» в «Обзоре» сохраняет отдельные копии записей в папке «02 ХТОНГРАД» и отправляет события в одноимённый календарь. Команда восстановления последней копии доступна в настройках Google.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → main → /docs → Save.

Для локальной проверки запустите `python -m http.server --directory docs` и откройте `http://localhost:8000`.
