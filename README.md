# 02 «Хтонград»

Мобильная писательская мастерская. Откройте [панель](https://htongrad.github.io/02-htongrad/) в Chrome.

- «Обзор» показывает последний текст, ближайшие сроки и свежие заметки.
- «Тексты» объединяют прозу, сценарии и публицистику. Форма определяет стартовые блоки и допустимую структуру. В редакторе можно свернуть, дублировать и переместить блок. Предпросмотр автоматически оформляет заполненные поля.
- «Заметки» можно хранить отдельно или прикреплять к проекту.
- «Календарь» показывает день, неделю или месяц. Событие можно связать с текстом.
- Знаки с пробелами пересчитываются в авторские листы по 40 000 знаков. Для сценариев можно задать целевой хронометраж в свойствах.

Рабочие данные сохраняются в открытом браузере. Меню «⋯ → Копии данных» позволяет экспортировать и восстановить JSON. Правила подключения Google описаны в [инструкции](google-sync-setup.md).

## Публикация

GitHub → Settings → Pages → Deploy from a branch → main → /docs → Save.

Для локальной проверки запустите `python -m http.server --directory docs` и откройте `http://localhost:8000`.
