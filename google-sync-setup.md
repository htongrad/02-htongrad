# Подключение Google к панели 02 «Хтонград»

Можно использовать проект Google Cloud, OAuth Client ID и ключ Google Picker панели «Личное». Для обеих панелей источник один — `https://htongrad.github.io`.

1. Откройте [Data Access](https://console.cloud.google.com/auth/scopes) в том же проекте Google Cloud. К разрешениям `openid`, `drive.file` и `calendar.events.owned` добавьте `https://www.googleapis.com/auth/calendar.calendarlist.readonly`. Панель использует его для поиска отдельного календаря «02 ХТОНГРАД».
2. В [панели «Хтонград»](https://htongrad.github.io/02-htongrad/) откройте «⋯ → Синхронизация Google». Вставьте OAuth Client ID, числовой Project number и ключ Google Picker. Нажмите «Сохранить настройки», затем «Подключить Google».
3. Через «Выбрать папку на Диске» выберите «02 ХТОНГРАД». В том же аккаунте должен быть отдельный календарь с таким же названием, принадлежащий этому аккаунту.
4. Нажмите «Синхронизировать». Проверьте файл «Хтонград — резервная копия.json» на Диске и пробное событие в календаре «02 ХТОНГРАД».

После первой успешной отправки открытая панель автоматически отправляет изменения, пока доступ Google действует. После истечения доступа в «Обзоре» появляется кнопка «Подключить Google». При открытой панели и действующем доступе восстановление интернета запускает повторную отправку. События, созданные непосредственно в Google, остаются там.

На новом телефоне после подключения Google и выбора папки нажмите «Восстановить с Диска». Восстановление добавляет отсутствующие записи по их идентификаторам и сохраняет текущие версии совпадающих записей. Если копия на Диске изменилась в другом браузере, панель приостанавливает перезапись до восстановления.
